ASIC FIELDNOTES
產業生態鏈TCO技術風險公司觀察
Semiconductor · AI Infrastructure · Investor Brief

客製化算力，
如何變成長期生意？

ASIC 不是「便宜版 GPU」，而是把特定工作負載、晶片架構、互連、軟體和供應鏈一起最佳化。這份研究以投資人能追蹤的商業指標，拆解這條價值鏈的機會與風險。

研究基準：2026 年 10 月 19 日繁體中文產業研究，不構成投資建議
核心判斷

價值落在「可重複量產」與「系統級交付」

設計服務商的營收和獲利取決於專案進度；真正的放大器是客戶產品能否跨代延續、晶圓與先進封裝能否交付，以及軟體堆疊能否讓硬體被持續使用。

01 / INDUSTRY

ASIC 的產業本質

專用化能提升特定工作負載的能效與成本效率，但也把設計成本、軟體責任與需求預測集中到較少的產品上。

架構

GPU / CPU 與 ASIC 的取捨

GPU 以大量平行運算和成熟軟體工具支援廣泛工作負載；CPU 擅長控制、通用邏輯與低延遲序列任務。ASIC 將特定算子、資料流、記憶體階層及 I/O 針對目標任務設計，能刪去不需要的通用功能。

結果可能是更好的每瓦效能、晶片面積或每次推論成本，但優勢取決於工作負載穩定、利用率高、軟體轉換成本可控。模型或演算法快速變化時，固定功能會變成彈性成本。

產業鏈

從需求定義到機櫃上線

雲端業者定義工作負載、性能、功耗和總成本目標；設計服務商協助架構實作、APR、時序收斂、實體驗證、高速 IP 整合與量產管理；晶圓廠、HBM、封裝測試、基板、伺服器與網路供應商共同決定交付能力。

晶片出貨只是中間站。軟體、散熱、供電、網路拓撲與機房電力共同決定整櫃的有效算力。

NRE

設計服務費：前期工程價值

Non-Recurring Engineering 是專案型設計、驗證與工程服務收入，常依里程碑認列。設計工作量、客戶驗收條件與專案延期會造成季度波動。相較量產代工，NRE 通常具有較高附加價值，但不能直接等同長期經常性收入。

Turnkey

量產統包：放大營收，也放大資金需求

量產階段可能由服務商協調晶圓、封裝測試，再交付晶片或完整產品。營收規模隨出貨量放大，但毛利率受採購成本、組合、良率與合約條款影響；墊款、存貨、應收帳款與取消風險會拉高營運資金需求。

看 EPS 時分清楚階段：設計案開始與工程里程碑偏向 NRE 驅動；投片、驗證到客戶導入仍有時差；量產出貨才可能帶來大幅營收增量。若量產毛利薄、應收款增速高，營收爆發不一定等於自由現金流同步改善。
02 / ECOSYSTEM

生態鏈與競爭位置

競爭不只在誰能設計出晶片，也在誰能把高速 I/O、封裝、供應鏈與系統軟體接成可部署的平台。

Broadcom · AVGO

客製加速器與網路互連平台

Broadcom 將客製 XPU、交換器、NIC、PHY 與光學元件放在同一 AI 基礎設施產品組合中，價值來自客戶共同設計、先進封裝整合與大規模網路部署。公開文件支持其服務 hyperscaler 與 AI 前沿模型客戶；市場常見的「約七成市佔」因口徑、年份與是否計入整體加速器不同，這裡不採用為已驗證事實。

追蹤：客製 AI 營收、主要客戶專案擴大、網通產品附加、量產節奏和客戶集中度。

Marvell · MRVL

客製 ASIC 與資料中心互連

Marvell 的差異化涵蓋高速 SerDes、ARM compute、矽光子、先進封裝與 die-to-die 互連，也提供 PAM DSP 等光通訊產品。公司年報說明客製產品依客戶規格開發，並列出 AI、資料中心與網路等應用；個別雲端合作的商業範圍需以公告和財報更新為準。

追蹤：客製計畫轉量產、客戶與產品集中、光互連產品組合、工程費用和毛利趨勢。

台灣生態：台灣設計服務商的定位從 IP 授權與前段設計，到後端實體設計、量產統包各有差異。TSMC 3DFabric Alliance 聚集封裝設計、EDA、IP、測試、記憶體與基板夥伴；Arm Total Design 則連結 Neoverse CSS、IP、設計服務、晶圓廠與韌體。加入生態系不是訂單保證，仍要看實際客戶專案與量產。

03 / TCO

什麼規模值得自研？

自研 ASIC 的經濟性不是單純比較晶片報價；要把一次性開發成本、部署數量、利用率、軟體維護和電力成本放進同一個模型。

成本池

一次性成本與每顆變動成本

一次性：架構與 RTL、驗證、EDA、IP 授權、光罩、流片、軟體移植、系統驗證與工程團隊。先進製程、HBM 與複雜封裝會推高首版成本。

每顆：晶圓、良率、封裝、HBM、測試、板卡 / 系統與物流。良率爬坡和採購條件會改變單顆成本。

損益平衡

用可比的「有效算力」比較

先定義同一服務水準下的單位工作量成本，例如每百萬 token 或每次推論。比較自研與外購方案的總成本，再用「自研固定成本 ÷ 每顆（或每台）節省金額」估計靜態損益平衡量。部署利用率、電價、冷卻、網路和折舊年限都會改變結果。

選讀：打開簡化版自研晶片損益平衡試算

僅作敏感度示範。金額皆為使用者輸入的假設，非產業報價或公司預測；模型未包含稅、折現、良率曲線、維運與殘值。

簡化損益平衡出貨量：200,000 顆
依目前假設，部署量高於簡化損益平衡點。
每年平均部署約 75,000 顆

公式：一次性成本 ÷ 每顆節省金額。若每顆節省為零，則無法達到損益平衡。真實決策應把 ASIC 對 GPU 的有效吞吐、利用率、軟體移植、折舊和融資成本一併建模。

推論的 OPEX 邏輯：大量、規律且長期存在的推論負載較容易攤提專用晶片成本。真正的比較指標應是達成同樣延遲與服務品質的總成本，而不是單看峰值 TOPS 或晶片功耗。若模型快速變動或利用率偏低，通用 GPU 的彈性可能更值錢。
04 / BOTTLENECKS

成長動能，與系統瓶頸

AI 推論需求擴大，讓工作負載最佳化更有價值；但算力只有在資料能送到、記憶體夠用、封裝可交付、軟體能部署時才有商業意義。

工作負載

訓練與推論的最佳化方向不同

訓練通常重視大規模矩陣運算、HBM 容量頻寬、跨加速器互連與彈性。推論會依模型、批次大小、上下文長度與延遲 SLA 變化，解碼常受記憶體頻寬限制。穩定而高量的推論服務較有機會透過客製化改善每次請求成本。

Chiplet / UCIe

模組化的收益不是免費的

Chiplet 可把大型單晶片拆成可重複使用的運算、I/O 或記憶體模組，降低單一大型裸晶的良率風險，也能跨製程整合。但封裝、die-to-die 互連、測試、熱設計、供應商協調與軟體驗證更複雜。UCIe 定義封裝內 die-to-die 互連的物理層、協定與軟體模型，開放標準不等於元件已可即插即用。

SerDes / 網路

互連頻寬決定叢集效率

112G 與 224G 世代的高速 SerDes 要在功耗、訊號完整性、通道損耗、誤碼率與可製造性間取捨。加速器算得再快，若交換器、NIC、光模組或 scale-up 網路供不上資料，整體利用率會下降。投資人可觀察交換器升級、光電互連滲透與客戶是否擴大整櫃部署。

封裝 / HBM

設計成功後仍須等產能與驗證

先進封裝將運算裸晶與 HBM 高密度整合，決定封裝尺寸、頻寬、功耗與成本。CoWoS、SoIC 等平台具有不同整合方式與適用情境；封裝產能、HBM 供應、基板與散熱都可能形成瓶頸。封裝排程延後會推遲客戶驗證和量產收入。

軟體

CUDA 的優勢是完整工具鏈與開發慣性

框架、編譯器、函式庫、除錯工具與部署服務共同形成遷移成本。PyTorch、Triton、vLLM 等工具降低部分硬體差異的使用門檻，但底層算子覆蓋、效能調校、除錯成熟度、分散式執行與企業支援仍需補足。硬體節省若被軟體維護成本抵消，就不是真正的 TCO 優勢。

供應鏈

大客戶自研與外部設計合作並存

CSP 可能自握架構、軟體和產品定義，同時外包部分實體設計、IP、製程移植或量產協調。外部服務商的價值是速度、經驗與交付能力；若客戶內部團隊成熟，供應商必須靠更深的技術整合和多代專案留存維持議價力。

分析提醒：單一專案宣布、試片成功、量產認證與大規模出貨是不同里程碑。確認營收轉折前，至少交叉檢查客戶公告、財報分類、產能供應與應收 / 存貨變化。
05 / RISK

風險不是附註，是估值的一部分

客製晶片專案可能有高成長，但收入能見度、客戶談判力和投資回收期限也更依賴少數決策者與單一產品週期。

In-sourcing

客戶把能力收回內部

客戶可能自行建立前後端設計、驗證與供應鏈團隊，讓外部服務商只承接尖峰工作或特定模組。關注服務商是否能從單次專案延伸到跨世代平台。

競爭

GPU 廠與大型 ASIC 供應商擴大服務

GPU 供應商可以透過產品組合、軟體、網路和系統方案回應專用晶片需求；其他大型 ASIC 廠也能以資本、IP 和客戶基礎競爭。替代方案會限制客製晶片的定價與經濟性。

法規 / 地緣

出口規則與跨境供應重排

先進運算晶片、製程設備、互連和終端用途可能受出口管制或授權條件影響。規則會調整，客戶、產品規格與出貨地點皆可能改變；需追蹤官方法規和公司揭露，不用舊門檻推論新規。

集中度 / 週期

一個大案的延誤就能改變季度數字

單一客戶占比偏高、產品轉換空窗、良率爬坡、封裝配額和資本支出延後，都可能使季度營收和毛利大幅波動。高營收成長若伴隨應收帳款或存貨急升，需檢查現金轉換。

每季可重複檢查的四個問題

① 設計案是否按期進入流片、驗證和量產？ ② NRE 與量產營收、毛利率的結構如何變化？ ③ 應收帳款、存貨、預付款與營業現金流是否支持營收品質？ ④ 前三大客戶占比、下一代專案和供應鏈瓶頸是否改善？

核心邏輯
先進節點複雜化提高客戶對經驗驗證 IP 的需求，量產後權利金可提高收入延續性。
財務 / 毛利
追蹤授權案和權利金的時間差、客戶量產進度、研發費用和毛利品質。
風險指標
單一案延遲、客戶集中、製程驗證支出、同類 IP 競爭及晶片景氣循環。
估值框架：對設計服務商，市場會為高成長與大型量產案支付溢價，但要用機率加權情境衡量未來 EPS：案子成功且量產延續、量產延遲、案量縮減。對 IP 商，則看授權到權利金的轉化、客戶平台黏著與可持續研發能力。避免把單一年度的高峰營收直接資本化為永續獲利。

一般投資人的操作節奏

建立觀察：先確認公司實際參與價值鏈的位置，以及哪些收入已經量產。
追蹤驗證：每季核對專案里程碑、營收組合、毛利率和現金流。
管理風險：把單一客戶與單一專案視為集中風險，設定能承受的估值與部位上限。
避免追逐單一消息：客戶合作、Tape-out、試產與大量出貨各有不同證據強度。
